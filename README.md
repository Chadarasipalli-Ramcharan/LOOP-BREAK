# ⏳ LOOPBREAK

### RUN YOUR PAST. CHANGE YOUR FUTURE. BREAK THE LOOP.

**A 3D action runner where your previous run becomes your teammate.**

`RUN` → `OBSERVE` → `ADAPT` → `BREAK THE LOOP`

## 🎮 About the Game

Every run leaves an **Echo**. On the next loop, your past self replays the route and actions you recorded.

Use Echoes to activate switches, hold pressure plates, distract guards, collect objects, and open new paths. Learn from each attempt, plan your route, and uncover why the city keeps repeating.

> **What if your past self could run beside you?**

## ✨ Features

- ⏱️ **60-second time loops** with replayable runs
- 👤 **Echo system** with support for multiple previous runs
- 🏃 **Third-person runner gameplay** with three-lane movement
- 🚧 **Obstacles and puzzles**: jump, slide, dodge, activate, escape
- 💎 **Collectibles**: Time Shards, Chrono Coins, Memories, and Recordings
- 🌦️ **Changing atmospheres** including rain, fog, snow, sunset, and night
- 📖 **Story chapters** and clues about the mysterious Observer
- 🏁 **Four modes**: Story, Loop, Endless, and Challenges
- 💾 **Local save** for progress, settings, and cosmetics

## 🕹️ Controls

| Action | Desktop | Mobile |
|---|---|---|
| Steer | `A / D` or arrow keys | Swipe left / right |
| Jump | `Space` | Swipe up |
| Slide | `C` or `Ctrl` | Swipe down |
| Sprint | Hold `W` or `↑` | Automatic running |
| Brake / wait | Hold `S` or `↓` | Hold **HOLD** |
| Dash | `Shift` | Tap **DASH** |
| Interact | `E` | Tap **USE** |
| Reset loop | `R` | Tap **RESET** |
| Pause | `Esc` or `P` | Pause button |

*Mobile sprint is not currently available; DASH gives you a short speed burst.*

## 🌍 Story Worlds

Explore routes inspired by **Paris**, the **Verdant Wilds**, **Dustfall**, **Frostline**, **Monsoon City**, **Fractured Reality**, and the **Chrono Core**.

The mystery unfolds across eight chapters, from **First Loop** to **Break the Loop**. Watch for strange clocks, repeated events, hidden recordings, and messages from **The Observer**.

## 💠 Collect & Progress

- **Time Shards** — collect them during runs.
- **Chrono Coins** — spend them on character cosmetics.
- **Memory Fragments & Lost Recordings** — discover optional story clues.
- **Echo Cores** — rare progression items.
- **Abilities** — unlock Time Dash, Echo Sync, Slow Time, and Phase Step.
- **Missions** — complete objectives and challenges.

## 🛠️ Built With

**React · TypeScript · Three.js · Vite · Tailwind CSS · Web Audio API**

LOOPBREAK runs in the browser and saves progress locally. No account, database, or environment variables are required.

## 🚀 Run Locally

**Requirements:** Node.js `20.19+` or `22.12+`

```bash
git clone https://github.com/Chadarasipalli-Ramcharan/LOOP-BREAK.git
cd LOOP-BREAK
npm install
npm run dev
```

Open the local URL shown in your terminal, usually `http://localhost:5173`.

Create a production build with:

```bash
npm run build
```

The production files are generated in `dist/`.

## ☁️ Deploy

Import the GitHub repository into **Vercel** or **Netlify** and use:

| Setting | Value |
|---|---|
| Build command | `npm run build` |
| Output directory | `dist` |
| Environment variables | None |

Push future changes to GitHub to trigger a new deployment.
